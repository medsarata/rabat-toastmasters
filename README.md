# Rabat Toastmasters Club – site web

Site statique trilingue (FR / EN / AR) du Rabat Toastmasters Club (club 05894368, District 107).

- `index.html` : page principale
- `album.html` : album photo (filtres + visionneuse)
- `js/album-data.js` : liste des photos de l'album — **pour ajouter une photo**, déposez l'image dans `img/album/` et sa miniature dans `img/album/thumbs/`, puis ajoutez une ligne dans ce fichier.
- `js/main.js` : traductions EN / AR (le français est dans le HTML)
- `css/style.css` : styles

Déployé sur Netlify : chaque push sur `main` republie le site.
